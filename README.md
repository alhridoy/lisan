# Academic Search Hub

A powerful academic research tool that helps researchers find, analyze, and understand academic papers using AI. Built with Next.js, TypeScript, and OpenAI.

## Features

- Search academic papers from multiple sources
- Generate AI-powered paper summaries
- Analyze research queries
- Generate structured summaries of multiple papers
- Calculate relevance scores
- Generate deep research analysis
- Search arxiv and Semantic Scholar
- Generate novel research ideas
- Chat-based interactions

## Environment Variables

The following environment variables are required:

- `OPENAI_API_KEY`: Your OpenAI API key
- `TAVILY_API_KEY`: Your Tavily API key for enhanced search capabilities

## Deployment

This application is configured for deployment on Vercel:

1. Fork this repository
2. Sign up for [Vercel](https://vercel.com)
3. Create a new project and import your forked repository
4. Add the required environment variables in Vercel's project settings
5. Deploy!

## Local Development

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file with your API keys
4. Run the development server:
   ```bash
   npm run dev
   ```

## Tech Stack
